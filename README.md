# Glossário de Git da turma

Este repositório reúne um glossário de Git escrito pela turma, uma entrada por
pessoa. As entradas aceitas são publicadas automaticamente no site.

## Como contribuir

Você **não** tem permissão de escrita aqui. Para contribuir:

1. Escolha uma **issue** ainda sem dono e comente nele dizendo que é seu.
2. Faça um **fork** deste repositório e clone o *seu* fork.
3. Crie um branch com o nome do termo.
4. Copie `MODELO.md` para `glossario/<termo>.md` e escreva a entrada.
5. Empurre (`git push`) para o seu fork e abra um **pull request** para cá, com
   `closes #N` na descrição, apontando para o seu issue.
6. Revise o pedido de outra pessoa e responda à revisão que você receber.

## Como deve ser uma entrada

- O bloco entre `---` no topo, com `title:`, é obrigatório: é dele que o site
  monta a lista.
- De duas a quatro linhas, **com as suas palavras**.
- Pelo menos um exemplo concreto: um comando, ou uma situação real.

Veja `glossario/commit.md` como exemplo.
